# Smart Hydroponic Web Dashboard

Web-based monitoring and control dashboard designed for automated smart hydroponic and agricultural systems. This project serves as a user interface for tracking system parameters and managing automated routines.

## Features
- **Real-Time Monitoring:** Displays live data from system sensors.
- **Web Dashboard Interface:** Built using HTML and Node.js backend.
- **System Control:** Interface elements to interact with automated hardware components.

## Tech Stack
- **Frontend:** HTML5, CSS/JavaScript
- **Backend:** Node.js, Express (`server.js`)
- **Package Management:** npm (`package.json`)

## Project Structure
- `index.html`: Main user interface dashboard.
- `server.js`: Backend server script handling routing and web communication.
- `package.json`: Project dependencies and configuration.
